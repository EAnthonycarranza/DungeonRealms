# Dungeon Realms: Game Vision

A Markdown copy of the original "Vibe-Code Blueprint" vision page, kept with
the code so every session starts from the same picture of the game.

> A 2.5D isometric, real-time fantasy RPG where heroes roam shared regions,
> smash monster packs, chase ridiculous loot, join friends for dungeons, learn
> Day Jobs, and eventually enter challenges that the game itself admits are a
> terrible idea.

Pillars: real-time combat, large roaming regions, 1–4 player dungeons,
build-changing loot, cartoon fantasy humor, mobile first.

## 01: Deep RPG, silly world

The systems are serious enough to support hundreds of hours of progression.
The characters, quest names, item flavor and world are allowed to have fun.
*Fight a world-ending dragon. The quest is called "THIS SEEMS BAD."*

Diablo-style roaming and build progression, with expressive cartoon fantasy.
Towns feel alive, dungeons are short enough for mobile sessions, and every
region stays useful through harder difficulties, events, crafting materials
and endgame rewards.

- **Level 1 → 60**: campaign progression and hero unlocks.
- **Hero Rank**: account-wide progression after level 60.
- **Spicy → Ridiculous**: difficulty tiers that add mechanics, not just HP.
- **Endgame forever**: Chaos Holes, Bad Idea Portals, Big Problems, raids and
  new seasons.

## 02: The core loop

Every session pushes the same hero journey forward, whether you have five
minutes or an hour:

**Buckleburg** (prepare and socialize) → **Explore** (roam and quest) →
**Fight** (real-time packs) → **Boss** (dungeons and events) → **Loot**
(build-changing drops) → **Grow** (gear, skills and rank).

## 03: The world: regions, not numbered stages

Each region is a real explorable space with quest hubs, enemy territories,
secrets, resources, caves, dungeon entrances, public events and a signature
boss.

| Levels | Region | Flavor |
| --- | --- | --- |
| 1–8 | Goblinwood | Forest roads, goblin camps, hidden caves, merchant trouble, Grizzlefang |
| 8–14 | Soggyroot | Bioluminescent mushrooms, giant roots, poison pools, Mother Mush |
| 20–26 | Bone-Rattle Marches | Crypts, necromancers, soul fire, skeletons with increasingly concerning job titles |
| 38–44 | Spookington | Haunted halls, angry paintings, possessed furniture, Lady Morvena |
| 50–56 | Brrrhold | Snow forts, blizzards, frost monsters, at least one angry snowman |
| 56–60 | Toasty Dragon Lands | Lava, ash storms, dragon ruins, a finale that gets legitimately dangerous |

## 05: Gameplay: action first, numbers second

Movement, aiming, dodging and positioning matter. Gear makes builds stronger
and stranger, but never replaces playing well.

- **Free movement**: left-stick movement through a 2.5D isometric world. No
  turns, no action points.
- **Skill aiming**: tap for fast abilities; hold and drag for lines, cones,
  dashes and ground-targeted attacks.
- **Universal dodge**: every hero gets an identity-specific evade (backflip,
  blink, spirit step, roll or charge).
- **Readable bosses**: telegraphs, phases, add waves, break windows and
  teamwork instead of giant static HP bars.
- **World interaction**: mine, gather, discover secrets, enter caves and
  trigger events without leaving the world.
- **Co-op combos**: classes set each other up with freezes, roots, breaks,
  buffs and shared mechanics.
- **Short sessions**: Quick Hunts, 8–15 minute dungeons and 3–6 minute Chaos
  Holes fit mobile play.
- **Shared regions**: see other adventurers roaming, then naturally join
  public events and Big Problems.

## 06: Loot and builds

Legendary gear is exciting because it alters abilities and creates builds,
not because it quietly adds 2.7% to something nobody notices.

> **Stormwood Bow** (legendary bow, Ranger only): +42 Attack, +8% Crit.
> *Stormcaller*: Piercing Arrow chains lightning to 2 nearby enemies after
> the first hit.

Players should describe builds by what they do, not by which stat number is
fourteen points higher.

## 07: Progression

The first 60 levels introduce the world and your hero. Endgame shifts toward
account-wide rank, builds, higher difficulties, challenge ladders and group
content.

1. **Hero levels 1–60**: story, skills, talents, gear systems, regions and
   dungeons unlock naturally.
2. **Hero Rank**: account-wide progression from 60, so alternate heroes don't
   start from zero.
3. **Build hunting**: legendary powers, Artifacts, talents and skill
   combinations become the real chase.
4. **Endgame loops**: Chaos Holes, Bad Idea Portals, Big Problems, hard
   dungeons and raids.

World difficulty: **Normal** (campaign) → **Spicy** (new mechanics) → **Very
Spicy** (more elites) → **Ridiculous** (serious challenge) → **Why Would You
Do This?** (endgame).

## 08: Multiplayer: MMO feeling without MMO chaos

Shared zones are sharded into manageable populations. Dungeons are controlled
1–4 player instances; raids can scale to 8 players later.

- **Shared regions**: about 20–30 visible players per shard, with friends and
  parties placed together.
- **Chaos Holes**: 3–6 minute randomized runs: fill the meter, spawn a
  Guardian, collect loot.
- **Bad Idea Portals**: a numbered difficulty ladder for solo and groups,
  with seasonal leaderboards.
- **Big Problems**: public boss encounters that nearby players pile into
  without formal matchmaking.

## 09: Economy and Day Jobs

Gathering and crafting are part of the world, not chores buried five menus
deep.

- **Mining**: ore veins in regions and dungeons. Enemies can interrupt you.
- **Herbalism**: regional herbs for potions, crafting and higher-tier recipes.
- **Blacksmithing**: craft and upgrade weapons with gathered resources and
  boss materials.
- **Alchemy**: potions, temporary buffs and special consumables.
- **Questionable Auction House**: player listings, buy orders and crafting
  orders, server validated.
- **Simple currency**: Gold, Shiny Bits, Guild Tokens and a cosmetic currency.
  No wallet full of nineteen meaningless tokens.

## 10: How it gets built: free-first, vibe-code-first

The technology is intentionally boring in the best way: common formats,
strong documentation and reusable systems that AI coding agents understand.

| Piece | Tech | Role |
| --- | --- | --- |
| `client/` | Flutter / Dart | App shell, menus, inventory, hero pages, guilds, marketplace |
| `game/` | Flame / Dart | Real-time movement, combat, AI, camera, projectiles, VFX, world interaction |
| `.tmx` | Tiled + flame_tiled | Isometric maps with collisions, spawn zones, quest triggers, resources |
| `game_data/` | JSON | Enemies, quests, loot, bosses, items and abilities as data |
| Persistence | Supabase / PostgreSQL | Accounts, heroes, gear, quests, currency, professions, guilds |
| Realtime | Colyseus / TypeScript | Authoritative multiplayer rooms once the offline game is fun |

## 11: Vibe-coding rules: build systems once, feed them data forever

The project survives vibe coding only if architecture is treated as
permanent memory rather than something every new AI session reinvents.

- **Search before creating**: never create a second InventoryManager,
  QuestController or EnemySystem because an agent forgot the first one.
- **Docs are memory**: ARCHITECTURE.md, CODING_RULES.md and system docs
  travel with the repository.
- **Data-driven content**: the 100th enemy should mostly be a definition file,
  not a new enemy engine.
- **Small tested tasks**: one feature, one enemy, one boss phase, one quest
  handler. Test, review, commit, then continue.

## 12: Roadmap: prove fun before scale

The first goal is not an MMO. **The first goal is a Ranger, Goblinwood, three
goblins and combat that feels good.**

1. **Movement**: Flutter shell, Flame world, Ranger, joystick, camera,
   collision.
2. **Combat**: basic attack, dodge, abilities, enemy AI, damage, death.
3. **Goblinwood**: Tiled map, quests, loot, mining, waypoint, event,
   Grizzlefang.
4. **Persistence**: Supabase auth, hero saves, inventory, quest progress,
   gear.
5. **Multiplayer**: 2 players → 4-player dungeon → shared zones → bosses →
   raids.

**The final target:** a game that feels huge because the systems are
reusable, not because the codebase is. New regions should mostly mean new
Tiled maps, enemies, quests, bosses, loot tables and art. New heroes use the
same combat framework. New seasons remix systems already built.
